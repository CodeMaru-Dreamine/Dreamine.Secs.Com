# Dreamine.Secs.Com Package QuickStart

공개된 `Dreamine.Secs.Com` 패키지만 참조하는 샘플입니다. 하나의 제한된 Process에서 Passive Equipment와 Active Host를 시작하고 Select, S1F1/F2, Linktest, Disconnect를 검증합니다.

```powershell
dotnet run --project samples/Dreamine.Secs.Com.PackageQuickStart
```

이 샘플은 로컬 Dreamine-to-Dreamine Smoke Test이며 외부 상호 운용성 또는 적합성 증거가 아닙니다.
