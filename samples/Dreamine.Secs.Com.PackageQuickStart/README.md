# Dreamine.Secs.Com Package QuickStart

This sample references only the published `Dreamine.Secs.Com` package. It starts a Passive Equipment and an Active Host in one bounded process, then verifies Select, S1F1/F2, Linktest, and disconnect.

```powershell
dotnet run --project samples/Dreamine.Secs.Com.PackageQuickStart
```

The sample is a local Dreamine-to-Dreamine smoke test. It is not external interoperability or conformance evidence.
